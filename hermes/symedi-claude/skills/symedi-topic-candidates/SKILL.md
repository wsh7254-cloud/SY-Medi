# 주간 주제 후보 정리

## When to Use

- 약사가 이번 주(또는 다음 주) 콘텐츠 주제 후보를 요청할 때
- 주 1회 예약 작업으로 실행될 때

## Procedure

1. **입력 확인**
   - 약사가 준 상담 질문 메모, 계절 이슈, 지난주 성과 메모를 읽습니다.
   - 이름·연락처·처방 내용 같은 개인정보가 보이면 즉시 멈추고 "개인정보를 지운 메모로 다시 주세요"라고 요청합니다.
2. **후보 만들기** — 15~20개를 만듭니다. 후보마다 아래 항목을 채웁니다.
   - 주제 (한 줄)
   - 대중의 질문 (실제 사람들이 물을 법한 문장)
   - 위험 등급
     - R0: 생활 정보
     - R1: 일반 건강 정보
     - R2: 용량·상호작용·금기·임신수유·소아·고령자·질환별 치료·성분 비교
     - R3은 후보에서 제외합니다.
   - 부산·동네와의 연결점 (없으면 "없음")
   - 약국 방문으로 이어지는 자연스러운 행동 (제품명 없이. 예: "남은 약은 약국 수거함으로")
   - 필요한 공식 출처 유형 (식약처, 질병관리청, 지자체 공지, 진료지침 등)
3. **레퍼런스 기록 규칙**
   - 인기 콘텐츠를 참고했다면 **직접 열어서 확인한 게시물만** 적습니다.
   - 적는 항목: URL, 게시일, 확인일(오늘), 페이지에서 직접 본 반응 지표
   - 지표를 보지 못했으면 "미확인"으로 씁니다. 추정치를 쓰지 않습니다.
   - 레퍼런스에서는 질문 유형·도입부 유형·구성만 태그로 적습니다. 문장·이미지를 옮기지 않습니다.
4. **균형 맞추기**
   - R2는 한 주에 2개 이하로 추천합니다.
   - R0·R1 중심으로 7개를 "추천 7선"으로 표시합니다.
5. **저장** — `topics/주제후보_<YYYY>-W<주차>.md`에 표 형태로 저장합니다.
6. **약사에게 요청** — 추천 7선을 요일별로 제안하고, 확정·교체할 주제를 골라 달라고 요청합니다.

## Pitfalls

- 조회수가 높다는 이유로 의학적으로 맞다고 판단하지 않습니다.
- 특정 제품·브랜드를 사게 만드는 주제("○○ 영양제 추천")는 후보에 넣지 않습니다.
- 위층 병원 등 특정 의료기관과 연결되는 주제는 넣지 않습니다.
- 확인하지 않은 조회수·게시일·URL을 만들어내지 않습니다.

## Verification

- 모든 후보에 위험 등급이 있고, R3이 0개입니다.
- 레퍼런스의 지표 칸은 실제 값 또는 "미확인"뿐입니다.
- 추천 7선 중 R2가 2개 이하입니다.

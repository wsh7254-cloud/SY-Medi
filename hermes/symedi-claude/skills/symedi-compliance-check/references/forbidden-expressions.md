# 금지·주의 표현 사전 (SY-Medi 운영 규칙)

이 사전은 **운영 규칙**이지 법령 목록이 아닙니다. "관련 규정"은 설계서(docs/content-system-design.md 부록 A·B)에 정리된 조사 결과이며, 표시가 [검색확인]이면 원문 재확인이 필요합니다. 이 목록은 약사만 수정합니다.

| 유형 | 표현 예시 | 대안 방향 | 관련 규정 (설계서 기준) |
|---|---|---|---|
| 효과 단정 | 완치, 100%, 확실히 낫는, 부작용 없음, 즉효, 특효, 기적의, 무조건 | 원문 범위의 표현: "도움이 될 수 있어요", "개인마다 달라요" | 약사법 제68조 과장광고 금지 (의약품·의약외품) [확인]; 식품표시광고법 부당광고 [검색확인] |
| 질병 예방·치료 (건강기능식품·일반식품) | 암 예방, 당뇨 치료, 혈압을 낮춰 주는 약 대신 | 질병 표현 삭제, 인정된 기능성 문구만 (심의 문구) | 식품표시광고법 제8조, 시행령 [별표 1] [검색확인] |
| 심의받지 않은 기능성 문구 (건강기능식품) | 면역력 쑥쑥, 피로 싹, 간 해독, 살 빠지는 | 제조·수입사가 받은 자율심의 문구로 교체 | 식품등의 기능성 표시·광고 자율심의 [검색확인]; 식품표시광고법 [검색확인] |
| 체험담 | 후기, 먹고 나았어요, 효과 봤다는 분이 많아요, 고객 사례 | 체험담 삭제 | 의약품 안전규칙 [별표 7] [검색확인] |
| 전문가 추천·보증 | 약사 추천, 약사가 고른, 약사가 먹는, 약사 인증, 약사 보증, 전문가 추천, 의사 추천 | 추천 표현 삭제, 일반 정보로 전환: "성분 표시를 확인하세요" | 식품표시광고법 [별표 1], 화장품법 시행규칙 [별표 5] 제2호 다목, 의약품 안전규칙 [별표 7] [검색확인] |
| 전문의약품 | 전문의약품 제품명 + 구매·문의 유도 | 성분 일반 정보만, 제품명·구매 유도 없이 | 약사법 제68조 제6항 [확인] |
| 경품·유인 | 사은품, 경품, 선착순 증정, 랜덤박스, 오늘만 할인 (의약품과 함께) | 삭제 | 의약품 안전규칙 [별표 7] 경품류 광고 금지 [검색확인]; 약국 호객 금지 [보도] |
| 병원 연계 | 위층 ○○의원 처방은 저희 약국에서, 병원 처방전 가져오시면 | 삭제 | 약사법 제24조 담합 금지 [검색확인] |
| 광고 표시 누락 | 협찬·공동구매·제휴 링크인데 "광고" 표시 없음 | 게시물 첫 부분에 "광고" 또는 "협찬" 표시 | 추천·보증 등에 관한 표시·광고 심사지침 [검색확인] |
| AI 표시 | 실사처럼 보이는 AI 이미지에 표시 없음, AI 가상 인물 | "AI 생성 이미지" 표시, 가상 인물 쓰지 않기 | 플랫폼 정책 [보도]; 공정위 가상인물 표시 개정안 [보도, 시행 확인 필요] |
| 판매 게시물의 약사 노출 | 판매·공동구매 게시물의 약사 얼굴, 약사 이름 표기, 약사 목소리로 제품 소개 | 얼굴은 삭제. 이름·목소리는 서면 법률 답변이 허용한 범위에서만 | 식품표시광고법 시행령 [별표 1] [검색확인]; 허용 범위는 설계서 A-7 질문 1 답변으로 확정 [확인 필요] |
| 공포 조장 | 이거 모르면 큰일, 당장 버리세요, 위험천만 | 사실 중심 표현 | 운영 규칙 [판단] |
| 개인정보 | 환자 이름·얼굴, 처방전, 약봉투 라벨, 모니터 화면 | 가리거나 삭제 | 개인정보보호법 제23조 민감정보 [검색확인] |

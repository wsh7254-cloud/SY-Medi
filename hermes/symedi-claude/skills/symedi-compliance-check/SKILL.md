# 광고·표현 점검

## When to Use

- 마스터 원고·플랫폼 초안을 만든 뒤
- 약사가 공동구매·협찬·이벤트 문구를 점검해 달라고 할 때

## Procedure

1. **사전 대조** — `references/forbidden-expressions.md`의 표현과 비슷한 말을 찾습니다. 글자가 달라도 뜻이 같으면 잡습니다.
2. **유형별 점검** — 아래 유형마다 해당 문장을 찾습니다.

   | 유형 | 보는 것 |
   |---|---|
   | 효과 단정 | 완치, 100%, 부작용 없음, 즉시 효과 |
   | 질병 표현 (건강기능식품·일반식품 문구) | 질병 예방·치료를 말하는 표현 |
   | 체험담 | 후기, "먹고 나았다", 고객 사례 |
   | 전문가 추천·보증 | 약사 추천, 약사가 고른·먹는, 약사 인증, 전문가 보증 |
   | 전문의약품 | 전문의약품 제품명이 구매 유도와 함께 나옴 |
   | 경품·유인 | 사은품, 경품, 랜덤박스, 할인 미끼 (특히 의약품과 함께) |
   | 병원 연계 | 특정 의료기관 처방을 이 약국으로 유도 |
   | 광고 표시 | 협찬·공동구매·제휴 링크인데 첫 부분에 "광고" 표시가 없음 |
   | AI 표시 | 실사처럼 보이는 AI 이미지에 표시가 없음, AI 가상 인물 사용 |
   | 개인정보 | 환자 얼굴·이름·처방전·약봉투·모니터 화면 |
   | 판매 게시물의 약사 노출 | 판매·공동구매 게시물에 약사 얼굴, 약사 이름, 약사 목소리(내레이션)가 있음 |

3. **결과 저장** — `compliance/<YYMMDD>_<대상>.md`에 표로 저장합니다.
   - 열: 위치, 문장, 유형, 관련 규정, 대안 표현
   - 관련 규정은 `references/forbidden-expressions.md`의 "관련 규정" 칸을 그대로 옮깁니다. 규정 원문을 새로 만들어 인용하지 않습니다.
4. **건강기능식품 문구일 때 추가 점검** — 기능성을 말하는 문장마다 "심의 문구 여부" 칸을 만듭니다.
   - 약사가 준 **자율심의 문구 원문**과 글자 그대로 같으면 "심의 문구와 일치"로 표시합니다. 이 비교는 `execute_code`로 합니다(공백만 정리하고 비교).
   - 심의 문구를 받지 못했거나 다르면 "미확인"으로 표시하고, 약사에게 제조·수입사의 심의 문구를 달라고 요청합니다.
   - 심의 문구가 아닌 기능성 표현을 새로 만들어 대안으로 제시하지 않습니다.
5. **판매 게시물의 약사 노출 점검**
   - 약사 얼굴이 있으면 삭제 대상으로 표시합니다(얼굴은 쓰지 않기로 확정).
   - 약사 이름이나 목소리가 있으면 "서면 답변 범위 확인 필요 (설계서 A-7 질문 1)"로 표시합니다.
   - 약사가 서면 답변의 허용 범위를 알려주지 않았다면, 그 게시물을 게시용으로 확정하지 않습니다.
6. **공동구매·협찬 문구일 때 추가 안내** — 결과 끝에 다음 문장을 붙입니다.
   > 약사 계정의 공동구매·협찬 문구는 법률 확인(설계서 부록 A-5, A-7) 전에는 게시하지 않습니다.
7. **결론 문장** — 발견한 것이 없으면 "점검 항목에서 발견된 것 없음 (법률 판단 아님)"이라고 씁니다.

## Pitfalls

- "합법입니다", "문제없습니다"라고 쓰지 않습니다.
- 규정 조항 번호를 추측해서 쓰지 않습니다. 참고표에 있는 것만 씁니다.
- 대안 표현이 원래보다 효과를 더 강하게 말하면 안 됩니다.

## Verification

- 결과 파일이 있고, 발견 항목마다 대안 표현이 있습니다.
- 공동구매·협찬 문구라면 법률 확인 안내 문장이 있습니다.
- 건강기능식품 문구라면 기능성 문장마다 "심의 문구 여부"가 적혀 있습니다.
- 판매 게시물이라면 약사 얼굴·이름·목소리 포함 여부가 적혀 있습니다.

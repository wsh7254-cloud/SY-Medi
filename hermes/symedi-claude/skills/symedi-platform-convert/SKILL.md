# 플랫폼별 초안 변환

권장 모델: 형식 변환이라 비싼 모델이 필요 없습니다. Claude Sonnet 5로 충분하고, 비용을 더 줄이려면 `/model`로 `claude-haiku-4-5`로 바꿔도 됩니다.

## When to Use

- 마스터 원고(`drafts/<YYMMDD>/master.md` 또는 최신 버전)가 준비되었을 때

## 고정 조건

- 약사 목소리 내레이션은 씁니다. **얼굴은 쓰지 않습니다(확정).** 영상은 **목소리 + 손·약장·수거함·약국 외관 같은 실제 촬영 컷 + 템플릿 자막**으로 구성합니다. 얼굴이 나오거나 거울·유리·모니터에 얼굴이 비치는 컷은 제안하지 않습니다.
- AI 아바타나 가상 인물은 쓰지 않습니다.
- 알약·약 포장·해부도는 AI 이미지로 만들지 않습니다. 실제 촬영 컷이나 단순 도형만 제안합니다.
- 이미지 속 한글·숫자는 디자인 템플릿에 넣을 문장으로 따로 적습니다. AI 이미지에는 글자를 넣지 않습니다.
- 채널끼리 "릴스에서 자세히" 같은 상호 참조를 넣지 않습니다.

## Procedure

`drafts/<YYMMDD>/` 아래에 파일을 만듭니다. 각 파일은 **내부용**(주장ID 태그 유지)과 **게시용**(태그 제거) 두 부분으로 씁니다.

1. `video.md` — 릴스·쇼츠·클립 공통 대본
   - 세로 9:16, 60초 이하
   - 내레이션 문장, 화면 자막 문장, 컷 제안(실제 촬영 컷 목록)
   - 플랫폼별로 따로: 인스타그램 캡션, 유튜브 제목·설명, 네이버 클립 제목·검색 키워드, 해시태그
2. `story-cards.md` — 인스타그램 스토리 카드뉴스 5~7장
   - 장마다 템플릿에 넣을 문장
   - 마지막 장: 약국 위치·운영시간 자리표시 `[약국 위치] [운영시간]`
3. `threads.md` — Threads 글 1개
   - 500자 이내, 질문형 마무리
4. `naver-blog.md` — 네이버 블로그 글 1개
   - 본문, 소제목, 출처 목록
   - 이미지 3~4장 배치: 장마다 "실제 촬영" 또는 "AI 배경(글자 없음)"을 표시하고, AI 이미지 아래 "AI 생성 이미지" 문구를 넣습니다.
   - 네이버 플레이스 안내 자리표시
5. `approval-A.md` — 약사 승인 요청 요약
   - 오늘의 주제, 핵심 메시지, 위험 등급
   - 주장 표: 주장ID, 표현, 출처 문서명, 근거 원문, 원문 저장 파일
   - 위험 표현 목록 (`symedi-compliance-check` 결과)
   - 6개 콘텐츠 파일 목록
   - 마지막 줄: "승인 / 수정 요청 / 보류 중 하나로 답해 주세요."

## 자체 점검 (execute_code)

- 게시용 문장에 마스터 원고에 없는 숫자가 있는지 확인합니다.
- 내부용 문장에 마스터 원고에 없는 주장ID가 있는지 확인합니다.
- 문제가 있으면 해당 채널만 한 번 다시 만들고, 그래도 문제가 있으면 약사에게 알립니다.

## Pitfalls

- 캡션에서 효과를 더 강하게 말하지 않습니다 (예: 원고의 "도움이 될 수 있어요"를 "좋아요"로 바꾸지 않기).
- 해시태그에 제품명·질병 치료 단정을 넣지 않습니다.
- 광고가 아닌 정보 콘텐츠에 "광고" 표시를 붙이지 않습니다. 협찬·공동구매 콘텐츠라면 이 스킬로 만들지 말고 약사에게 알립니다.

## Verification

- 파일 5개가 모두 있고, 게시용 부분에 태그가 없습니다.
- 새 숫자·새 주장ID가 0개입니다.
- approval-A.md에 위험 표현 목록이 있습니다.

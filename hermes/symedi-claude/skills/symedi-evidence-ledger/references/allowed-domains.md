# 허용 도메인 (근거로 쓸 수 있는 출처)

하위 도메인은 상위 도메인에 포함됩니다. 예: `nedrug.mfds.go.kr`은 `mfds.go.kr`에 포함됩니다.

| 도메인 | 기관·자료 | 용도 |
|---|---|---|
| `mfds.go.kr` | 식품의약품안전처, 의약품안전나라(nedrug) | 허가사항, 사용상 주의사항, e약은요, 안전성 서한 |
| `kdca.go.kr` | 질병관리청, 국가건강정보포털 | 질환·예방 정보, 예방접종 |
| `mohw.go.kr` | 보건복지부 | 정책·제도 |
| `me.go.kr` | 환경부 | 폐의약품 등 배출 제도 |
| `busan.go.kr` | 부산광역시 | 지역 안내(폐의약품 수거 등) |
| `law.go.kr` | 국가법령정보센터 | 법령 원문 |
| `hira.or.kr` | 건강보험심사평가원 | DUR, 의약품 정보 |
| `nhis.or.kr` | 국민건강보험공단 | 건강검진 등 제도 |
| `data.go.kr` | 공공데이터포털 | 식약처 공공데이터 설명 페이지 |
| `who.int` | 세계보건기구 | 국제 지침 |
| `cochranelibrary.com` | 코크란 라이브러리 | 체계적 문헌고찰 |
| `ncbi.nlm.nih.gov` | PubMed 등 | 진료지침·체계적 문헌고찰 원문 확인용 |

## 추가 규칙

- 부산 각 구청 도메인(예: 영도구 `yeongdo.go.kr`)은 약사가 허용하면 검사 코드의 `EXTRA_DOMAINS`에 넣습니다.
- 학술 논문은 체계적 문헌고찰·진료지침을 우선합니다. 개별 연구 1편만으로 효과를 단정하지 않습니다.
- 목록에 없는 도메인은 "참고만"으로 적고 근거로 쓰지 않습니다.
- 이 목록은 약사만 바꿉니다.

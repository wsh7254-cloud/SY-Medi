# 근거 장부 열 (25개, 순서 고정)

저장소의 `templates/evidence-ledger.csv`와 같은 머리행입니다.

```
주장ID,주제ID,콘텐츠 표현,위험등급,출처 문서명,출처 URL,출처 기관 유형,근거 원문,원문 위치,원문 저장 파일,발표일,개정일,확인일,적용 대상,예외·주의,인용 일치(코드),숫자·단위 일치(코드),뒷받침 판정(모델),출처 충돌,검증 상태,약사 검토 필요,약사 확인,사용 채널,승인 버전 해시,재확인 예정일
```

| 열 | 채우는 값 |
|---|---|
| 주장ID | `YYMMDD-C01` |
| 주제ID | `YYMMDD-주제요약` |
| 콘텐츠 표현 | 게시물에 들어갈 문장 |
| 위험등급 | R0 / R1 / R2 |
| 출처 문서명 | 페이지·문서 제목 |
| 출처 URL | 실제로 연 주소 |
| 출처 기관 유형 | 식약처 / 질병청 / 공공기관 / 허가사항 / 진료지침 / 체계적 문헌고찰 |
| 근거 원문 | 저장본에서 글자 그대로 복사 |
| 원문 위치 | 문단·표·페이지 |
| 원문 저장 파일 | `sources/YYMMDD/...` |
| 발표일 / 개정일 | 원문에 있을 때만, 없으면 "미확인" |
| 확인일 | 오늘 날짜 |
| 적용 대상 / 예외·주의 | 원문에 있는 범위만 |
| 인용 일치(코드) | 코드 출력: 일치 / 불일치 / 미검사 |
| 숫자·단위 일치(코드) | 코드 출력: 일치 / 불일치: … / 해당 없음 / 미검사 |
| 뒷받침 판정(모델) | 지지 / 부분 / 불충분 + (모델명) |
| 출처 충돌 | 없음 / 있음(내용) |
| 검증 상태 | 초안 / 출처확인 / 검증완료 / 보류 / 폐기 |
| 약사 검토 필요 | 예 / 아니오 |
| 약사 확인 | 약사가 직접 적음 (날짜·메모) |
| 사용 채널 | 비워 둠 (발행 단계에서 기록) |
| 승인 버전 해시 | 비워 둠 (승인 단계에서 기록) |
| 재확인 예정일 | R2만 확인일 + 6개월 |
